# Marketing · CB Grup Barna × Time Chamber

Web pública: https://anafernandezduran78-dev.github.io/marketing/

## Com afegir una peça (des del mòbil o l'ordinador)
1. Obre la carpeta on va (p. ex. `club/reels` o `time-chamber/disseny`) a github.com.
2. **Add file → Upload files** → arrossega el fitxer (mp4, png, jpg, pdf) → **Commit changes**.
3. En 1-2 minuts surt a la web. El nom del fitxer és el títol que es veu.

## Regles
- Mai fotos o vídeos amb cares de menors sense consentiment escrit de la família.
- Mai contractes, convenis, dades de famílies ni claus.
- Fitxers de menys de 25 MB (límit de pujada web de GitHub).
